# Privacidad

Este documento complementa la [política de privacidad de Jurisprudenciator](https://jurisprudenciator.lexiaipro.org/politica-de-privacidad).

## Datos tratados y finalidad

Las skills de este plugin ayudan al profesional a rellenar formularios y a elaborar borradores de escritos. Según lo que el usuario aporte, pueden leer nombres, datos de contacto, hechos y documentación del asunto, incluidos datos sensibles. Los escritos generados se guardan donde el usuario decida.

## Servicios que reciben datos

Claude procesa las instrucciones y documentos conforme a las condiciones y configuración de la cuenta de Anthropic. Jurisprudenciator recibe los argumentos de las herramientas invocadas para consultar fuentes jurídicas y verificar citas; las consultas describen el problema jurídico y deben evitar datos identificativos del cliente. El plugin no incorpora almacenamiento propio ni telemetría independiente.

## Conservación y control

Los documentos permanecen donde el usuario los guarde hasta que los gestione o elimine. Claude y Jurisprudenciator aplican sus propios plazos de conservación. Para cuestiones sobre Jurisprudenciator, ejercicio de derechos y soporte: [política y contacto](https://jurisprudenciator.lexiaipro.org/politica-de-privacidad) e [incidencias](https://jurisprudenciator.lexiaipro.org/incidencias).

El plugin está destinado a profesionales. El abogado debe revisar los borradores y las fuentes antes de utilizarlos.
